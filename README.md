One emoji, chosen to make a stranger smile: 🌞 — the sun with face. It is
warmth with a gentle smile on it, read the same way by a stranger of any age
or background, and it is a deliberate pick rather than the first smiley that
comes to mind — with no intimacy, sarcasm or flirtation that would read
oddly from someone unknown. The program writes that single emoji, and
nothing else, to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```
